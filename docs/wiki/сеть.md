# Сеть (LAN)

Статус: активная разработка в ветке `lan`. Полный дизайн — неизменяемый снимок
`docs/specs/2026-09-11-lan-match-design.md`, план — `docs/plans/2026-09-11-lan-match.md`.
Реализован пока только транспорт и handshake; лобби, снапшоты, ввод, fairness и
пауза ещё не сделаны.

## Модель

Host-authoritative, тонкий клиент: симулирует только хост, клиенты строят `Match`
из потокового `MatchSetup` и проигрывают снапшоты рендер-состояния. Топология —
звезда. Стек — `boost::asio`: **TCP** control-канал (реализован), **UDP** realtime
(в плане).

## Модуль `src/net` (статическая `netlib`)

| Файл | Роль |
|---|---|
| `nettypes.hpp` | константы (protocol/port/limits/rates), `NetAddress`, `e_NetMessageType`, `e_NetConnectionState`, `NetInputFrame`. |
| `netbuffer.hpp/.cpp` | сериализация little-endian: u8/16/32/64, bool, float, string, `Vector3`, `Quaternion`; `NetWriteU32LE`/`NetReadU32LE`. |
| `netmessages.hpp/.cpp` | `NetClientHello`, `NetServerHello`, `e_NetRejectReason`, (де)сериализация. |
| `netassets.hpp/.cpp` | `NetGetBuildHash()` (git-хеш из CMake), `NetGetDataVersion()`/`NetGetDataHash()` (`databases/default/manifest.json`), `NetGetAnimationHash()` (SHA-1 листинга `media/animations`), `NetSha1()`. |
| `netserver.hpp/.cpp` | TCP-сервер: bind/listen, `NetServerConnection` (async read/write), проверка `ClientHello`, ответ `ServerHello`, сигнал `sig_OnHandshake`. |
| `netclient.hpp/.cpp` | TCP-клиент: resolve/connect, отправка `ClientHello`, приём `ServerHello`, состояния `Connect/Handshake/Connected`, сигнал `sig_OnHandshake`. |

Формат кадра TCP: 4 байта длины (LE) + payload = 1 байт типа сообщения + тело.
Каждая сторона держит очередь записи; чтение асинхронное (`async_read`).

## Handshake

`ClientHello` несёт `protocolVersion`, `buildHash`, `dataVersion`, `dataHash`,
`animationHash`, `playerName`. Сервер сравнивает всё со своими значениями и
отвечает `ServerHello{accepted, reason, reasonText, sessionId}`. Причины отказа:
`ProtocolMismatch`, `BuildMismatch`, `DataVersionMismatch`, `DataHashMismatch`,
`AnimationMismatch`, `LobbyFull`, `Unknown`. Несовпадение медиа-набора (анимаций)
важно потому, что клиент резолвит анимации по имени.

## Инструменты

- **`tools/nettest`** — headless smoke-тест: поднимает `NetServer` и `NetClient`
  на `127.0.0.1` в одном процессе, ждёт обмен handshake, печатает результат
  (`PASS`/`FAIL`, код выхода 0/1).

## Не сделано

UDP-канал ввода и снапшотов, зеркальное лобби, `MatchSetup`-стрим, remote-режим
`Match`, `NetHIDDevice`, host input-delay, пауза/дисконнект/реконнект — см. план.
