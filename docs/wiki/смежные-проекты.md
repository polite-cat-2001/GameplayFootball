# Смежные проекты

Экосистема вокруг GameplayFootball: три проекта данных (Transfermarkt) и два open-source
симулятора карьеры как референс. Детали канона и конвейера — [[данные-из-transfermarkt]].

## Проекты данных

### football_collection (`C:\Users\Egor\Desktop\projects\football_collection`)

Flutter-игра про коллекционирование карточек футболистов. Данные — **bundled JSON в assets**,
сети в рантайме нет.

- `assets/json/`: `prepared_tm_players_profiles.json` (1255 игроков сборных),
  `prepared_tm_players_market_values.json` (1254), `prepared_tm_teams.json` (48 сборных),
  `prepared_tm_coaches_profiles.json` (47), `prepared_tm_legends_profiles.json` (136),
  `prepared_tm_clubs.json` (473), `prepared_tm_teams_emblems.json`.
- Рейтинги игроков (SoFIFA-подобные: overall/maxSpeed/lowPass/shoots/defence/dribbling/
  goalkeeper) — **не в JSON**, а захардкожены в `lib/features/draft/domain/models/ratings.dart`
  (ключ — TM-id).
- Пути к фото собираются шаблонно: `assets/raster/{players_faces|coaches_faces|legends_faces|
  teams_flags|teams_emblems}/{id}.{jpg|png}`.
- Возраст и `joinedClubOn` вычисляются на лету из истории стоимости (хак; в каноне — `birth_date`).
- Модель игрока: `id, name, height, citizenship[], position{main,other}, foot, marketValue,
  outfitter, team_shirt_number, club_id/name, team_id/name, maxMarketValue`.

### transfermarkt-api (`C:\Users\Egor\Desktop\projects\transfermarkt-api`)

Форк [packee-dev/transfermarkt-api](https://github.com/packee-dev/transfermarkt-api) (FastAPI,
Python 3.9+). От upstream отличается: модуль национальных сборных, модуль тренеров, фикс
nullable-полей. Каждый вызов — **живой запрос к TM** (скрейпинг XPath). Лимит slowapi на деплое
`2/3seconds`, локально выключен.

Проверенные эндпоинты (2026-08-29):

- `GET /players/{id}/profile` — полный профиль (рост, гражданство, позиции, клуб, стоимость, outfitter).
- `GET /players/{id}/market_value` — текущая стоимость + история `[{age,date,clubId,clubName,
  marketValue}]` + ranking.
- `GET /clubs/{id}/players` — **состав клуба**: позиция, дата рождения, рост, фут, стоимость.
- `GET /clubs/{id}/profile` — colors[] (HEX), стадион, лига, эмблема.
- `GET /national-teams/most-valuable` — 250 сборных.
- `GET /national-teams/{id}/players` — состав сборной + `shirtNumber` (добавлено).
- `GET /coaches/{id}/profile` — тренер (починено: `extract_from_url` резал домен).
- `GET /competitions/{id}/clubs` — клубы лиги; `GET /competitions/search/{name}` — ES1/ES2 и т.п.

Правки форка за сессию: `extract_from_url` (срезка домена + `AttributeError`), возраст в составе
сборной (`td[2]`), поле `shirtNumber`.

### transfermarkt_scrapper (`C:\Users\Egor\Desktop\projects\transfermarkt_scrapper`)

Python-клиент канона: `tm_1…tm_999` дёргают локальный API, скачивают фото, чистят и собирают
`prepared_*.json` для коллекционки. **Сломан** (запускался с банами TM):

- задержки по умолчанию 0, воркеры 8–20, статичный UA Chrome 91 (2021), голый `requests` без
  TLS-fingerprint, ретраится только 503, 429 молча глотается;
- `tm_999` неидемпотентен — перезаписывает собственные входные файлы;
- в ветке `fix` уже намечено решение: rate-limit, curl_cffi, SQLite-resume-кэш.

## Симуляторы карьеры (референс)

Сравнение подсистем (полный разбор в клоне репо во временной папке, 2026-08-29):

| Аспект | open-football (Rust, Apache-2.0) | openfootmanager (Rust+Tauri+React, GPL-3.0) |
|---|---|---|
| Матч-сим | агентный: поле 840×545, тик 10 мс, физика мяча | зонный + дуэли `att/(att+def)`, минутный цикл |
| Скорость | тяжёлый, rayon-батчи | лёгкий, целый тур мгновенно |
| Расписания | круговой (circle method) | круговой + сдвиг с окон сборных |
| Кубки | нокаут + byes + reseed | группы→нокаут, berth-квоты в континент |
| PR/континенты | с учётом групп/сплитов, парашюты | пирамида + квалификация |
| Трансферы | многофазные переговоры, клаузулы, аренды, оценка стоимости | интерес→оффер→контр-оффер, аренды с опцией |
| Развитие | еженедельный тик, возрастные кривые, CA/PA 1–200 | сезонный aging, тренировки, potential |
| Финансы | broadcast/matchday/commercial, долги, FFP | бюджеты, зарплаты, ledger |
| Репутация | базовая сущность, влияет на всё | есть |
| Счастье/мораль | очень глубоко (PlayerMind, желания) | morale_core, обещания |
| Комментарий | нет | детерминированный i18n-текст |
| Сейвы | нет (автономный мир) | SQLite + миграции |

**Выводы для карьерного режима GF** (этап 5): быстрый зонный матч-сим брать как модель из
openfootmanager (фон матчей, которые не играешь в 3D); круговой генератор расписания, пирамиду
лиг и мультипликативную оценку стоимости — из open-football. Код копировать можно только из
open-football (Apache-2.0 совместим с лицензией GF); openfootmanager (GPL-3.0) — только идеи.
